1. Overview

This Privacy Policy describes how Drifty ("the bot", "we") collects, stores, uses, and protects information when you interact with the bot on Discord. We are committed to handling your data responsibly and transparently.

Drifty is not a commercial product. No data is sold, monetised, or shared with advertisers. Data collection exists solely to enable the bot's features.

2. Information We Collect

Drifty collects and stores the following information in a local SQLite database:

User Data
  • Discord user ID — a numerical identifier assigned by Discord
  • Username — your Discord username at the time of interaction
  • Message count — number of messages sent in servers where Drifty is active
  • Activity timestamps — when you were last seen active
  • Trust & reputation scores — internally computed values for personalised responses
  • Streak data — consecutive activity days
  • RPG/game stats — Cursed Energy, domain, grade, shikigami, vows, skills, etc.
  • Behavioural notes — short AI-generated summaries of your chat style (max 300 chars)
  • Callback phrases — memorable snippets from your messages stored for personality callbacks
Server Data
  • Guild ID — Discord's identifier for your server
  • Channel IDs — identifiers for channels where Drifty operates
  • Server configuration — feature toggles, personality modes, chaos stats, mood scores
  • Channel setup — IDs of designated Drifty channels
Message / Conversation Data
  • Chat history — up to the last 30 messages per channel stored for AI context (rolling window)
  • Anonymous confessions — content submitted via ?confess, stored in memory only (not database)
  • Highlights — short snippets flagged as funny/notable, stored in memory only

3. How We Use Your Information

  • To deliver personalised AI chat responses based on interaction history
  • To power RPG game mechanics, economy balances, and progression tracking
  • To detect returning users, streaks, milestones, and absences
  • To enable rivalry, alliance, and drama arc features
  • To moderate bot behaviour (silence system, trust scores)
  • To generate server-wide summaries, recaps, and statistics

We do not use your data for advertising, profiling beyond bot functionality, or sharing with third parties beyond what is necessary to operate the bot.

4. Third-Party Services

Drifty passes message content to the following third-party APIs for AI processing:

External APIs Used
  • Cerebras Cloud SDK — message content is sent to generate AI responses. Governed by Cerebras' Privacy Policy
  • Google Text-to-Speech (gTTS) — text is sent to Google for TTS audio generation in voice channels. Governed by Google's Privacy Policy

By using Drifty's AI chat and TTS features, you acknowledge that message content may be processed by these third-party services.

5. Data Retention

  • Chat history — automatically trimmed to the most recent 30 messages per channel
  • Callback phrases — capped at 50 entries per server, oldest removed automatically
  • Confession data — stored in memory only; lost on bot restart
  • User profiles — retained as long as the bot is present in the server
  • Post-removal — server data may be retained for up to 30 days after Drifty is removed from a server

6. Data Security

Drifty stores data in a local SQLite database with WAL journaling enabled. While we take reasonable precautions:

  • Data is not encrypted at rest beyond the host system's own security
  • No payment or sensitive personal information is ever collected
  • Bot credentials (tokens, API keys) are stored as environment variables, not in the database
Drifty is not a security-critical application. Do not share sensitive personal information through the bot.

7. Your Rights

You have the right to:

  • Request data deletion — server admins can wipe chat memory with ?resetmemory. For full user data deletion, contact the bot developers
  • Request data access — contact the developers to request a summary of your stored data
  • Opt out of AI features — server admins can disable random replies and AI interactions via ?panel
  • Opt out of confessions — admins can disable the confessions feature server-wide

8. Children's Privacy

Drifty is not directed at children under the age of 13. We do not knowingly collect data from users under 13. If you believe a child has interacted with the bot, please contact us to have their data removed.

We may update this Privacy Policy from time to time. Continued use of Drifty after changes are posted constitutes acceptance of the revised policy. The "last updated" date at the top of this page will reflect any changes.
